# SmartPost Desktop v2.2.2 — Hotfix Denuncias por texto

- Denuncias ahora recibe una sola caja de texto con múltiples identificadores.
- Acepta N° de guía, Remito o Guía Agente mezclados y sin indicar el tipo.
- Epresis confirma el tipo buscando en los tres campos; los prefijos solo optimizan el orden.
- Si el mismo envío se pega con más de un identificador, se deduplica.
- El seller ya no se pide al operador.
- El botón HACER DENUNCIA primero resuelve automáticamente los pedidos y continúa.
- Solo se solicitan datos obligatorios que Epresis no haya podido proporcionar.
- Incluye el hotfix visual de títulos de la pantalla principal.
