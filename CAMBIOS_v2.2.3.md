# SmartPost Desktop v2.2.3

- La ventana principal puede redimensionarse libremente y la pantalla Denuncias usa scroll para adaptarse a pantallas chicas.
- Los paquetes dentro del relato se listan como: `REMITO - Seller: SELLER`.
- La opción de violencia/daños requiere selección explícita; SmartPost no inventa ese dato en una denuncia oficial.
- La fecha de nacimiento sigue tomándose de Epresis/perfil guardado o se solicita si falta; no se genera una fecha ficticia a partir del DNI.
